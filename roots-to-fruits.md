# Gridwise — Roots to Fruits

## Concept

Roots to Fruits is Gridwise's interactive learning progression system.

Inspired by Duolingo's learning path and branching skill trees, learners develop their Excel knowledge through a living garden.

## The Seedling

Every learner begins as a seedling.

Learners can preview and customise their final anthropomorphic plant or flower avatar.

Their avatar develops towards this chosen appearance as they progress.

## The Root System

Roots represent learning pathways.

Each root contains lessons that teach specific Excel skills.

As learners complete lessons, roots grow and unlock new connected lessons.

Different roots may intersect where skills depend on one another.

## Learning Tree Structure

Roots to Fruits is a scalable learning progression system designed to support multiple software courses.

A central tree represents foundational knowledge.

Each software course develops through interconnected root systems containing lessons and skill pathways.

Roots grow and unlock as learners progress.

## Above-Ground Exercises

Practical exercises become available as learners develop the necessary knowledge.

These exercises allow learners to demonstrate what they have learned.

## Fruit and Mastery

Successfully completing practical challenges produces fruit.

Fruit represents demonstrated skill and achievement.

## Learning Framework

- Roots = Learn
- Above Ground = Apply
- Fruit = Mastery

Individual lessons follow Gridwise's existing Teach → Lesson → Apply framework.

## Development Scope

The initial implementation will focus exclusively on Excel.

Future courses may include Word, PowerPoint, operating-system fundamentals and other software.
