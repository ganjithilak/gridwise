# Course content

Lessons are data. How to add one is in the project README ("Adding or changing a lesson").

Before writing or editing any learner-facing text, read:

- [docs/editorial-standards.md](../../docs/editorial-standards.md): voice, feedback, terminology, technical accuracy, lesson structure.
- [docs/curriculum-map.md](../../docs/curriculum-map.md): what each lesson introduces and requires, the farm story, and the figures that carry from lesson to lesson.

Exercise IDs are permanent: rewrite an exercise under its existing ID, add new ones to
`src/content/ids.ts`, and move removed ones to `RETIRED_IDS`.
